# 東京23区 用途地域マップ

東京23区の**用途地域・高度地区・防火／準防火地域**を地図上で確認できる静的サイト。
地点をクリックすると建ぺい率・容積率・高さ制限などが表示され、その地点を
**各区の公式都市計画GISで直接開くリンク**が出る。

## できること

- 地図をクリック、または住所検索（国土地理院ジオコーダ）で地点を指定
- 用途地域／高度地区／防火・準防火地域の3レイヤーを切り替え表示
- 地点の詳細：用途地域名・建ぺい率・容積率・高さの最高限度・外壁後退距離・
  敷地面積の最低限度・特例容積率適用地区・高度地区の種別と高さ・防火指定
- 斜線型（第一種〜第三種）の高度地区には北側斜線に関する注意を表示
- 23区中21区は、クリックした地点を**区の公式GISの地図中心**として開ける
- 残る千代田区・杉並区は、区のシステム側に座標を渡す手段が存在しないため、
  **東京都の全都域サービスへ地点指定で**送り、区の公式サイトを補助リンクとして併記する
- 背景地図の切り替え（淡色／標準／航空写真）

## データ

| | |
|---|---|
| 出典 | [東京都都市整備局「都市計画決定情報GISデータ」](https://catalog.data.metro.tokyo.lg.jp/dataset/t000008d0000000028) |
| ライセンス | CC BY 4.0（加工・再配布可。出典表示が必要） |
| データ基準日 | 都市計画決定 令和7年3月31日現在（2026-08時点） |
| 配布元の更新頻度 | 公称「1年ごと」 |
| 区界 | 国土交通省 国土数値情報「行政区域データ」 |
| 背景地図 | 地理院タイル（国土地理院） |

コード値の意味は同データセットの「データ定義書」に従っている
（用途地域=`TUP3F1`、高度地区=`TUP5F1`、防火=`TUP6F1` ほか）。

**週次ジョブは「毎週データが新しくなる」ものではない。** 配布ZIPの
`Last-Modified` を毎週見張り、**変わった週だけ**取り込んで再デプロイする。
元データが年1回更新なので、ほとんどの週は「変更なし」で即終了する。

## 使い方（ローカル）

`ローカルで開く.bat` をダブルクリック。ブラウザで http://localhost:8787 が開く。
（`file://` で直接開くと、ブラウザの制限でデータを読み込めないので不可）

## データを更新する

```bash
pip install -r requirements.txt
python build/build_site.py          # 配布元に更新があった時だけ再構築
python build/build_site.py --force  # 強制的に再構築
```

出力先は `site/data/`。区ごとに分割した GeoJSON（全体で約11MB）を書き出す。
所要時間は再構築ありで30秒ほど。

## 構成

```
build/
  build_site.py   取得・座標変換・区ごとの分割・書き出し
  codes.py        コード表と配色（表示側にも codes.json として渡る）
  wards.py        23区の定義と各区公式GISのリンクテンプレート
site/             ← これが公開されるフォルダ
  index.html / app.js / style.css
  vendor/         MapLibre GL JS（同梱）
  data/           build_site.py の出力
.github/workflows/weekly.yml   週次の更新チェック
```

地点の判定は、読み込んだ GeoJSON に対する JavaScript 側の内外判定で行っている
（地図の描画状態に依存しないため、描画前でも住所検索が動く）。
表示範囲に入った区の分だけを遅延読み込みする。

# 公開する手順（Cloudflare Pages）

Webサイトを公開したことが無くても進められるよう、順を追って書いてある。
どちらのアカウントも無料。**費用はかからない。**

## 1. GitHub にコードを置く

1. https://github.com/signup でアカウントを作る
2. https://github.com/new で新しいリポジトリを作る
   - Repository name：`youto-map` など
   - **Public**（Cloudflare Pages の無料枠は Private でも使えるが、Public の方が手順が少ない）
   - 「Add a README file」等のチェックは**入れない**
3. このフォルダ（`youto_map`）を、作ったリポジトリに push する

```bash
cd youto_map
git init -b main
git add .
git commit -m "東京23区 用途地域マップ"
git remote add origin https://github.com/<あなたのID>/youto-map.git
git push -u origin main
```

`site/data/` の約11MBもそのままコミットする（Cloudflare Pages はリポジトリの中身を
そのまま配信するため）。

## 2. Cloudflare Pages につなぐ

1. https://dash.cloudflare.com/sign-up でアカウントを作る
2. 左メニュー **Workers & Pages** →**Create** → **Pages** → **Connect to Git**
3. GitHub を認証し、`youto-map` リポジトリを選ぶ
4. ビルド設定：
   - Framework preset： **None**
   - Build command： **（空欄のまま）**
   - Build output directory： **`site`**
5. **Save and Deploy**

1〜2分で `https://youto-map-xxxx.pages.dev/` のようなURLが発行される。
以降、GitHub に push するたびに自動で再デプロイされる。

独自ドメインを使う場合は、Pages プロジェクトの **Custom domains** から追加できる
（Cloudflare でドメインを管理していれば SSL 込みで無料）。

## 3. 週次の自動更新を有効にする

`.github/workflows/weekly.yml` が入っているので、push した時点で有効になる。

- 毎週月曜 07:00（日本時間）に配布元の更新を確認する
- 更新があった時だけ `site/data/` を再構築してコミット → Cloudflare Pages が自動デプロイ
- GitHub の **Actions** タブから手動実行もできる（`force` を on にすると強制再構築）

> GitHub Actions は、リポジトリに60日間まったく変更が無いとスケジュール実行を
> 自動停止する。元データが年1回更新なので、これに引っかかる可能性がある。
> Actions タブで手動実行するか、たまに何かコミットすれば再開する。

## 制約と注意

- **このサイトは参考情報**。用途地域の境界は道路中心線や敷地境界と厳密には
  一致しないことがあり、境界付近の土地は必ず区の窓口で確認すること。
  そのために各区公式GISへのリンクを置いている。
- ポリゴンは1mの許容誤差で簡略化してある（表示サイズを抑えるため）。
- 区界でクリップする際、隣接区とわずかに重なるよう約30m外側に広げている
  （境界に隙間が出ないようにするため）。
- 千代田区は高度地区の指定そのものが無い。

### 各区公式GISへのリンクについて（2026-08-07 調査）

千代田区と杉並区は、**区のシステム側に地点を渡す口が存在しない**ことを確認済み。

- 千代田区（ArcGIS Experience Builder）… URLパラメータ非対応。`center` を緯度経度でも
  地図の座標系（平面直角座標系 sr=2451）でも渡したが、`identify` の座標も `mapExtent` も
  毎回まったく同一で、常に既定範囲を読む。
- 杉並区（すぎナビ・Vue）… ルーター定義が `/mp/:mp` と `/mp/:mp/vlf/:vlf` のみで、
  クエリパラメータを読む処理が `app.js` に1箇所も無い。旧UI `/webgis/` は未提供。

この2区は東京都都市整備局の
[都市計画情報等インターネット提供サービス](https://www2.wagmap.jp/tokyo_tokeizu/)（全都域）へ
地点指定で送っている。今回のデータの発行元そのものなので、出典としても筋が通る。

**このサービスの `mpx`/`mpy` は日本測地系として解釈される。** `gprj` の値を変えても
変わらない。世界測地系のまま渡すと約460m北西へずれるため、`app.js` の
`wgs84ToTokyo()` で変換してからURLに埋めている。

検証結果（変換後の座標を渡し、サイト側の座標表示・現在地表示と突き合わせ）：

| 地点 | 現在地表示 | 誤差 |
|---|---|---|
| 中野区沼袋1-32-1 | 中野区沼袋１丁目 | 0.9m |
| 千代田区丸の内 | 千代田区丸の内１丁目 | 1.7m |
| 杉並区阿佐谷 | 杉並区阿佐谷南１丁目 | 1.6m |

中央区は当初トップページ送りにしていたが、`map.php?lat=&lon=` が利用許諾に阻まれず
直接開き、タイル座標が指定地点と一致することを確認したため、地点指定リンクに変更した。
